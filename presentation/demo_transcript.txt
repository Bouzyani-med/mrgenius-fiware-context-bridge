This is Context Bridge, a working Python prototype by Mohammed Bouzyani, Mr Genius Morocco. It integrates the actual Antares version zero point two NGSI LD broker. This video is a narrated walkthrough of captured interface steps. The running application is available separately for a live demonstration. The snapshot contains 138 real public service-map records and 24 organisation entities. These are attributed City of Helsinki Service Map records, licensed under Creative Commons Attribution four point zero. No sponsor data is used.

The interface searches records returned from the broker, then ranks their names and addresses using corpus-fitted T F I D F. Here, searching Kannelmaki returns its library record. You can inspect the published address, telephone, website, source URL and linked organisation identifier. Missing contact fields remain unavailable. Similarity is a retrieval score, not a probability or proof that a public record is current. The API query is visible in the transport evidence.

The local review action performs a real broker roundtrip. It first reads the target, creates a separate ReviewDecision entity with a Relationship to that target, updates the target's local review state using PATCH, and reads the result back with GET. The interface confirms the verified result. This is a local evidence annotation. It does not authorise a change on behalf of a business owner, and no municipal registry or external listing is modified.

The negative test shows that a query with no supported terms returns zero matches and disables review. Ten automated tests run against a fresh real Antares process. They cover source and organisation preservation, coordinate order, ranking, missing fields, invalid-action write blocking and verified review readback. The broker is in memory and resets on restart. Both servers bind loopback. This is a prototype without production authentication, not an ETSI compliance certification. The public repository contains the code, upstream license, actual HTTP evidence and run instructions. We are entering the independent FIWARE award route and can demonstrate the working application live.
